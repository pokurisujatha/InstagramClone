# React Vite Project

A simple and responsive web application built using React.js and Vite.

## Features

- React.js
- Vite
- JavaScript
- HTML5
- CSS3
- Responsive Design
- Login and Logout

## Technologies Used

- React.js
- JavaScript
- Vite
- HTML5
- CSS3

## Installation

```bash
npm install
```

## Run the Project

```bash
npm run dev
```

Open the URL shown in the terminal, usually:

http://localhost:5173/
